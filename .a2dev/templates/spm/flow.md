sPM Sustain Flow (Conversation Mode)

Steps
1) Gate Check: summarize open items, severity, owners
2) Security Findings: CVEs, SAST/DAST, privacy
3) Rollout Plan: staging, canaries, feature flags, rollback
4) Observability: SLOs/SLIs, traces/logs, dashboards, alerts
5) Operations: runbook readiness and on-call handoff

Per‑Step Pattern
- Ask 2–3 prompts to confirm readiness.
- Summarize current state and gaps.
- Offer: change/continue/skip next (name it).

Closeout
- Release readiness statement and next owner.
- If any gate is FAIL, list the minimal steps to PASS.
